# Tus imágenes

Guardá acá las fotos que quieras usar, por ejemplo:

- `portada.webp`: foto principal de ustedes.
- `avatar.webp`: foto que se mostrará sobre el mapa.

Después editá `src/data/projectConfig.ts` y cambiá `coverImage` y `avatarImage`.

Para cuidar el rendimiento en celular, se recomienda usar WebP y que cada imagen pese menos de 500 KB.
